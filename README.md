# 더나은365한의원 홈페이지

대구 달서구 계대동문로 124 · 053-581-0175

별도 빌드 없이 `index.html` 한 파일로 동작하는 정적 홈페이지입니다.

## 구성
- 첫 화면: 실시간 진료 상태(한국 시간 기준 "지금 진료 중 / 마감"), 전화 버튼
- 원장 소개 · 진료 철학 · 진료 과정 · 진료 영역 · 둘러보기
- 자주 묻는 질문
- 오시는 길: 진료 시간표(오늘 요일 강조), 지도, 네이버 지도 / 카카오맵 바로가기
- 모바일: 햄버거 메뉴, 하단 고정 "전화 상담 / 오시는 길" 바

## 직접 채워야 할 부분
`index.html`에서 `TODO` 또는 `예시`로 검색하면 나옵니다.
- 사진 (방법은 `images/README.md` 참고)
- 원장님 인사말 · 경력
- 진료 철학 / 진료 영역 실제 내용
- 푸터 사업자등록번호

> 의료광고 관련 법규상 치료 효과 보장, 다른 의료기관과의 비교, 환자 후기 등은 문구에 넣지 않는 것이 안전합니다.

## 미리보기
`index.html`을 브라우저로 열면 됩니다.

## 배포 (GitHub Pages)
저장소 Settings → Pages → Branch를 `main` / `(root)`로 지정하면
`https://<계정>.github.io/thebetter365-site/` 주소로 공개됩니다.
