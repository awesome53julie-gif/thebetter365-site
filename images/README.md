# images/

한의원 사진을 이 폴더에 넣어 주세요. 권장 파일명:

| 파일명 | 들어갈 위치 | 권장 비율 |
|---|---|---|
| hero.jpg | 첫 화면 대표 사진 | 4:5 (세로) |
| director.jpg | 원장 소개 | 4:5 (세로) |
| gallery-1.jpg ~ gallery-6.jpg | 한의원 둘러보기 | 4:3 (가로) |

`index.html`에서 `<div class="photo">…</div>`를
`<img class="photo" src="images/hero.jpg" alt="설명">` 처럼 바꾸면 됩니다.
가로 1600px 이하, 300KB 안팎으로 줄여서 올리면 빠르게 열립니다.
